# Get started with Corion 4.0

Run the setup wizard, choose a search provider and import bookmarks if desired. Customize your homepage and try split view with two pages.

- Ctrl+K opens the command palette.
- Ctrl+Shift+L opens the local library.
- Shift+Esc opens browser health tools.
- Use workspaces to organize tabs and offline reading to save page text.

Restored background tabs load when selected. New profiles use automatic idle tab management; existing saved preferences remain in place. Back up important data before trying recovery or upgrade workflows. Translation sends the requested page information to Google only after the browser's consent step.
