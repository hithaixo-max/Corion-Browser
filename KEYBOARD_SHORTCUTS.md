# Keyboard shortcuts

These shortcuts are supported by Corion's current Windows browser shell. They are handled in both the native shell and embedded web content. Website-specific shortcuts may differ.

| Action | Shortcut |
| --- | --- |
| Focus and select the address bar | `Ctrl+L` |
| New tab | `Ctrl+T` |
| New private tab | `Ctrl+Shift+P` |
| New window | `Ctrl+N` |
| New private window | `Ctrl+Shift+N` |
| Close the current tab / selected tabs | `Ctrl+W` |
| Reopen a recently closed normal tab | `Ctrl+Shift+T` |
| Next tab | `Ctrl+Tab` or `Ctrl+Page Down` |
| Previous tab | `Ctrl+Shift+Tab` or `Ctrl+Page Up` |
| Choose tabs 1–8 | `Ctrl+1` through `Ctrl+8` |
| Choose the last eligible tab | `Ctrl+9` |
| Open / close the tab chooser | `Ctrl+Shift+A` |
| Downloads | `Ctrl+J` |
| Find in page | `Ctrl+F` |
| Next / previous find result | `F3` / `Shift+F3` |
| Reload a website | `F5` or `Ctrl+R` |
| Reload a website bypassing its cache | `Ctrl+F5`, `Shift+F5` or `Ctrl+Shift+R` |
| Increase / decrease page zoom | `Ctrl++` / `Ctrl+-` |
| Reset page zoom | `Ctrl+0` |
| Toggle fullscreen | `F11` |
| Exit fullscreen / dismiss the active shell panel when available | `Escape` |
| Performance panel | `Shift+Escape` |

Reload is intentionally disabled on Corion's own homepage. Recently closed private or burned tabs are excluded from normal tab restore. In a floating video window, `F11` enters or leaves the video-only fullscreen view; `Escape` returns from that view.

The shell shortcut mappings were checked against the current implementation for this documentation. This table does not claim a new live keyboard interaction check for every row.
