# Corion press information

Corion 4.0 — Finishing Touches is an early Windows x64 browser release by Coritex Studio. It includes a customizable homepage, split view, workspaces, research tools, offline text reading, a command palette and a unified local library. It uses .NET 10 and Chromium 156 via CefSharp.

The installer is unsigned; updates are manual and remote diagnostics upload is not deployed. No universal performance, anonymity or website compatibility guarantee is made. Existing image and trailer assets may show older versions and must not be labelled as new 4.0 captures. Browser source remains private. See the release notes, privacy information and retained asset/third-party notices.
