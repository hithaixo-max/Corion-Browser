# Security reports

Use [GitHub private vulnerability reporting](https://github.com/hithaixo-max/Corion-Browser/security/advisories/new) for sensitive reports. Include the affected version, reproduction steps and impact; exclude passwords, tokens and personal browsing data. Do not post exploit details in a public issue.

Corion 4.0 is the current early Windows release. There is no guaranteed response time or bounty. The installer is unsigned and update delivery is manual. Browser source is private; this public repository hosts the website, documentation and release assets.
