# Corion 4.0 troubleshooting

If startup fails, check that Windows is x64 and the .NET 10 Desktop Runtime and Visual C++ prerequisites installed successfully. Close all Corion windows before retrying an upgrade. Use the checksum to check a damaged download.

For a website issue, record the URL, Corion version, Windows version, steps, and expected behavior. Remove private information before opening a public issue. DRM, extensions and some taskbar integrations have known limitations. Recovery tools should be used with a backup of important profile data.

Updates are manual. Remote crash/usage upload is not deployed. The old 3.24 troubleshooting toolkit has not been requalified as a 4.0 tool. Security vulnerabilities should use the private route in SECURITY.md rather than public issues.
