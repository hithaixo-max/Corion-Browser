Getting started

  1. Download the setup EXE and check its version.
  2. Run setup for your Windows account, then open Corion.
  3. Choose your search provider and import bookmarks from an exported HTML file.

Existing profiles are stored separately from application files. Keep a private backup before trying development builds.

Upgrading from an earlier version?

Close Corion before running setup. The 4.10 installer keeps your profile data. Automatic update delivery is not enabled; future installers will be published here.
