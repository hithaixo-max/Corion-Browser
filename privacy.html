Your data, explained.

Plain information about this website and the browser.

Updated 9 November 2026 · Technical data notes for Corion 4.0.

This website

This site includes no advertising pixels, analytics scripts, external fonts or newsletter forms. It does not ask for a browser account. Hosting infrastructure processes network requests and access information. This public website is hosted by GitHub Pages, which may process access information under GitHub’s privacy policy.

Downloads and feedback links go to GitHub, which handles those visits under its own privacy policy. This site does not automatically download or install browser updates.

Local browser data

Normal profiles store bookmarks, history, settings and other saved content locally. Private tabs use isolated temporary browsing sessions. Private browsing does not hide your network address from websites or your network provider.

Online services

Search queries go to your chosen search provider. Optional online suggestions can send typed search text to that provider; Corion 4.0 defaults new profiles to suggestions off, and private tabs disable them. Websites and extensions have their own network behavior.

Translation in 4.0 asks before opening Google Translate with selected text or a page URL. Optional music recognition sends an acoustic fingerprint after a user action and microphone permission.

Diagnostics and updates

Corion 4.0 has no enabled automatic Corion crash or usage uploader. Local managed logs are bounded and omit free-form exception messages; native Chromium logs may still contain personal information. A separate diagnostic hosting project is not a live browser upload service.

Corion 4.0 uses manual update downloads. The updater, when configured, will contact release hosting for version information and update packages; the final deployment and disclosures must be completed before it is enabled.

Saved reading and backups

Offline reading, notes and workspaces remain in the local profile. Backup files can contain private saved content. Keep them private, and delete them when no longer needed.

Policy status

The full worldwide launch policy still requires final publisher identity, contact details, retention and provider facts. This page explains reviewed behavior; it does not claim that a production legal review has been completed.
