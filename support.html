Quick answers

How do I bring my bookmarks?

Export bookmarks as an HTML file from your previous browser. In Corion, open the bookmark manager and choose Import HTML. Corion does not automatically copy your passwords or logged-in accounts.

Can I install Corion on a phone or Mac?

The available release is for Windows x64. There is no official Corion macOS, Linux, Android or iOS download on this site.

Does private browsing make me anonymous?

No. Private tabs use isolated temporary sessions, but websites, your network and online service providers can still receive requests.

Where are the 4.0 features?

They ship in Corion 4.0. Open the command palette with Ctrl+K, or search your saved library with Ctrl+Shift+L. Read the release page for known limits.

Will it update automatically?

Corion 4.0 includes update controls, but automatic delivery is not enabled. Download future releases from this official website or GitHub Releases.

Something isn't right?

Include your Corion version, Windows version and clear steps to reproduce the issue. Review screenshots before posting; GitHub issues are public.
